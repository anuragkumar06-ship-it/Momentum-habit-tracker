Step 1

Get the file

You have one file — momentum.html — that's your entire app. Here's what to do with it.

01
Save the file to your computer
You received the file as momentum.html — save it somewhere you can find it easily, like your Desktop or a folder called "Projects".
💡 Rename it to index.html before deploying
02
Open it in your browser
Double-click the file — it opens directly in Chrome, Edge, or Firefox. No server needed. It works exactly like a website, right from your desktop.
Your file path will look like
file:///Users/yourname/Desktop/momentum.html
03
Start adding habits
Click "+ Add Habit", name your habit, pick a colour and icon, set your daily target — and start tracking from today. Your data saves automatically to your browser's local storage. Nothing leaves your device.
✓ Data is private — only on your device

🟢 Method A — Netlify Drop No account needed

The fastest way to get your app online. Takes under 2 minutes.

  • Rename your file from momentum.html to index.html
  • Open your browser and go to netlify.com/drop
  • Drag and drop your index.html file into the big box on the page
  • Wait 5–10 seconds — Netlify gives you a live URL instantly
  • Copy your URL — it looks like amazing-name-123.netlify.app
  • Open it on your phone and tap "Add to Home Screen"
⚠️
Without an account, Netlify Drop URLs expire after 24 hours. For a permanent link, use Method B below.

🔵 Method B — Netlify Free Account

Best option. Free forever. Permanent URL. You can even rename your site.

  • Go to netlify.com and sign up free — use your Google account
  • Click "Add new site" → "Deploy manually"
  • Rename your file to index.html and drag it into the deploy box
  • Your site goes live at a random URL like random-name.netlify.app
  • To rename: go to Site Settings → Change site name → type something like my-momentum.netlify.app
  • Share your custom URL with anyone — they can use it too
✅
Your URL is permanent and free. You can redeploy any time by dragging a new file — your URL stays the same.

Deploy with GitHub Pages

For developers or anyone who wants to learn GitHub. Free forever. Auto-deploys when you update your file. Watch the full tutorial below.

How to Deploy with GitHub Pages — Full Tutorial

01
Create a GitHub account
Go to github.com and sign up for a free account. It takes 2 minutes. You only need to do this once.
02
Create a new repository
Click the green "New" button. Name your repo something like momentum-habit-tracker. Keep it Public. Click "Create repository".
Recommended repo name
momentum-habit-tracker
03
Upload your file
Inside your new repo, click "uploading an existing file". Drag your file — make sure it's named index.html. Click "Commit changes".
⚠️ File must be named exactly: index.html
04
Enable GitHub Pages
Go to your repo → Settings → Pages. Under "Branch", select main and folder /root. Click Save.
05
Your site is live!
Wait 1–2 minutes, then your app is live at:
https://yourusername.github.io/momentum-habit-tracker
Share this link anywhere. To update the app later — just upload a new index.html file to the same repo.

FAQ

Common questions

Everything you might wonder about.

Will my data be lost if I clear my browser?
Yes — Momentum uses your browser's local storage. If you clear your browser data, your habits will be deleted. To avoid this, use the Export feature inside the app to back up your data as a JSON file before clearing.
Can I use it on multiple devices?
Each device has its own local storage, so data doesn't sync automatically between devices. However, you can use the Import/Export feature to manually transfer your data between devices.
Is it really free? Forever?
Yes. The file is yours. Netlify's free plan and GitHub Pages are both permanently free for static files like this. There are no hidden costs, no subscriptions, and no ads.
Can I share it with friends?
Absolutely. Once deployed, just share the URL. Your friends can open it and use their own version — their data stays on their device, separate from yours.
Do I need to know coding to use this?
Not at all. You don't need to touch any code. Just follow the steps in this guide — rename the file, drag it to Netlify, and you're done. No technical knowledge required.
Can I edit the app or add features?
Yes! Since it's a single HTML file, you can open it in any text editor (like VS Code or even Notepad) and edit the code. If you're not a developer, you can describe the changes to an AI like Claude or ChatGPT and it will write the code for you.
